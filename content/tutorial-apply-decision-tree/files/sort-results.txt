The illustration shows how the columns are selected to perform a sort of the results.

The Sort button is highlighted, and an arrow extends to a dialog window labeled Select columns to sort by.

The dialog has two columns. The left column is labeled Available Columns. Two data values are shown in this column: CLAS_DT_1_1_PCT and CUSTOMER_ID. 

The right column is labeled Selected Columns. This column contains the values CLAS_DT_1_1_PRED and CLAS_DT_1_1_PROB.

Between the columns, there are a set of selector buttons that move the data from the Available columns to the Selected Columns , these indicate: transfer selected, transfer all, remove selected, remove all.

To the right of selected columns are a set of radio buttons, one labeled Ascending and the other Descending. The Descending radio button is selected.

At the bottom of the dialog window, the Apply Sort button is highlighted.
