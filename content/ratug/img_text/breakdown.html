Description of the illustration breakdown_section.png

This image in the breakdown section of the Workload Analysis shows the Elapsed Time, SQL Statements by Performance, and SQL Statements by Plan Change.

The Elapsed Time tile shows the total amount of elapsed time for all executions of all captured statements within that time period.

The SQL Statements by Performance tile provides the number of statements for each group. It is important to correlate this data with the data available in the summary section.

The SQL Statements by Plan Change lists the SQL details thats helps you analyze. If the new plan shows performance improvements, then you must determine if a single execution is faster or slower.
