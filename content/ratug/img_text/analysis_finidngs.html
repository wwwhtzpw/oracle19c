Description of the illustration analysis_findings.png

This image shows the findings in the analysis metrics.

The Metrics tile includes statistics for all important metrics and displays an overview of all the differences.

The Metrics table displays Metric Name, Metric Change (Before or After), Net Absolute Impact on Workload (%), and Net Impact on SQL (%).

The Findings tile lists the type of error and the error message that is associated with the metrics like Elapsed Time, CPU Time, Buffer Gets, Cost, Reads, and Writes.
