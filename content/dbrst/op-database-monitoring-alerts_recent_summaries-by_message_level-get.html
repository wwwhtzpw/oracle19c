Get count of recent alerts by message level

get

/database/monitoring/alerts_recent_summaries/by_message_level

Group by message level on V$DIAG_ALERT_EXT originating within the last 7 days. In an Oracle RAC environment, data returned by this service may vary according to the instance to which a session is connected. A client requires SQL Administrator role to invoke this service.

Request

There are no request parameters for this operation.
