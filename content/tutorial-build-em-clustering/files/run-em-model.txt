The illistration shows the workflow of the EM model.

On the left, there is an icon representing a data source, labeled MINING_DATA_TEXT_BUILD_V. On the right there is an icon representing a clustering node, labeled Clust Build.

An arrow extends from the data source to the clustering node, indicating a connection betweent the two.

To the right of the clustering node, there is an icon representing the applied model result labeled Apply Model. An arrow representing a connection extends from the clustering node to the Apply Model icon.

A data source icon labeled MINING_DATA_TEXT_APPLY_V sits above the Apply Model icon. An arrow representing a connection extends from from this icon to the Apply Model icon.
