Creating the OSRACDBA Group for Database Installations

You must designate a group as the OSRACDBA group during installation. Members of this group are granted the SYSRAC privileges to perform day to day administration of Oracle databases on a RAC cluster.

Create the OSRACDBA group using the groups name racdba unless a group with that name already exists:
  1. Enter the following command:
    # smit security
  2. Choose the appropriate menu items to create the racdba group.
  3. Press F10 to exit.
