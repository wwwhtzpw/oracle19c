Installing ODBC Drivers for IBM AIX

If you intend to use ODBC, then install the most recent ODBC Driver Manager for IBM AIX on POWER Systems (64-bit).

Download and install the ODBC Driver Manager from the following website:

http://www.unixodbc.org

Oracle ODBC driver on IBM AIX is certified with ODBC Driver Manager 2.3.4. To use ODBC with Oracle Database, you must also install the following package:

gcc 4.2.1 or later
