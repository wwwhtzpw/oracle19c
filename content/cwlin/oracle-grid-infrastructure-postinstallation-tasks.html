10 Oracle Grid Infrastructure Postinstallation Tasks

Complete configuration tasks after you install Oracle Grid Infrastructure.

You are required to complete some configuration tasks after Oracle Grid Infrastructure is installed. In addition, Oracle recommends that you complete additional tasks immediately after installation. You must also complete product-specific configuration tasks before you use those products.

Note:

This chapter describes basic configuration only. Refer to product-specific administration and tuning guides for more detailed configuration and tuning information.

  • Required Postinstallation Tasks
    Download and apply required patches for your software release after completing your initial installation.
  • Recommended Postinstallation Tasks
    Oracle recommends that you complete these tasks after installation.
  • Adding a Local GIMR to an Existing Cluster
    You can add a local Grid Infrastructure Management Repository (GIMR) to an existing cluster if you did not create a GIMR as part of the Oracle Grid Infrastructure installation.
  • Using Remote GIMR for Oracle Standalone Cluster
    Starting with Oracle Grid Infrastructure 19c Release Update (19.14), you can use a remote GIMR for an Oracle Standalone Cluster, if you did not create a GIMR during the installation.
  • About Changes in Default SGA Permissions for Oracle Database
    Starting with Oracle Database 12c Release 2 (12.2.0.1), by default, permissions to read and write to the System Global Area (SGA) are limited to the Oracle software installation owner.
