  • Use your quick navigation keys to move between buttons, frames, checkboxes, headings, list items, and so on.
  • A dotted line around an object in a slide indicates that the object is optional. A line with alternating dots and dashes around an object indicates that the object can run as a thread or an operating system process. These object types are also described in the notes.
