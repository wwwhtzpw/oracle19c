The Configure Management page gives you two selections with which you can select to register with Enterprise Manager: 1) Configure Enterprise Manager (EM) Database Express. 2) Register with Enterprise Manager Cloud Control.

If you select to configure using EM Database Express, then there is a field below this selection where you can enter the EM Database Express port number, and a check box that you can select so that the EM Database Express port is configured as a global port.

If you select to register with Enterprise Manager Cloud Control, then there are input fields for you to provide information for the CMS host, the CMS port, the Enterprise Manager admin user name, the Enterprise Manager admin password, the DBSNMP user password, and the ASMSNMP user password.
