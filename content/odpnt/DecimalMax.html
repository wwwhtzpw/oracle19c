Max

This method returns the maximum value of the two supplied OracleDecimal structures.

Declaration

public static OracleDecimal Max(OracleDecimal val1, OracleDecimal val2);

Parameters

  • val1

    An OracleDecimal structure.

  • val2

    An OracleDecimal structure.

Return Value
