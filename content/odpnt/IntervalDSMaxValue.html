MaxValue

This static field represents the maximum value for an OracleIntervalDS structure.

Declaration

// C#
public static readonly OracleIntervalDS MaxValue;

Remarks

Maximum values:

  • Day: 999999999

  • hour: 23

  • minute is 59

  • second: 59

  • nanosecond: 999999999
