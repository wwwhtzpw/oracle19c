Configuring User Accounts

When installing Oracle Grid Infrastructure for a cluster, you run the installer software as an Administrator user. During installation, you can specify an Oracle Home user.

Before starting the installation, there are a few checks you need to perform for the Oracle Installation users, to ensure the installation will succeed.

  • Configuring Environment Variables for the Oracle Installation User
    The installer uses environment variables set for the Oracle Installation User.
  • Verifying User Privileges to Update Remote Nodes
    You must ensure that operations that are performed on multiple nodes can be performed during installation of the Oracle Grid Infrastructure software.
  • Managing User Accounts with User Account Control
    To ensure that only trusted applications run on your computer, Windows Server provides User Account Control.
