Broadcast Requirements for Networks Used by Oracle Grid Infrastructure

Broadcast communications address resolution protocol (ARP) and User Datagram Protocol (UDP) must work properly across all the public and private interfaces configured for use by Oracle Grid Infrastructure.

The broadcast must work across any configured VLANs as used by the public or private interfaces.

When configuring public and private network interfaces for Oracle RAC, you must enable ARP, which is necessary for VIP failover. Do not configure NOARP.
