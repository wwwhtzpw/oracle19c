6 Installing Oracle Instant Client

Starting with Oracle Database 19c Release Update (19.10), Oracle Instant Client is available on Linux x86-64 and Linux for Arm (aarch64) platforms.

You can install Oracle Instant Client by downloading either the zip files or RPMs from the Oracle Instant Client download page on the Oracle website.
