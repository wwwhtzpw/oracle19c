Deployment Checklist for Oracle RAC Database

Use the checklist to review the deployment methods for Oracle Real Application Clusters.

Table 1-1 Deployment Checklist for Oracle RAC Database

Item Task
To Deploy Oracle RAC software

Install Oracle RAC Database software using Oracle Universal Installer (OUI).
To Deploy Oracle Database software and create Oracle RAC databases

Install Oracle RAC Database software using Oracle Universal Installer (OUI) and choose to create a database.
To Create Oracle RAC database in an already-installed Oracle home.

Use Oracle Database Configuration Assistant (DBCA). See Creating Oracle RAC or Oracle RAC One Node Databases with Oracle DBCA for more information about creating database using DBCA.

Complete the installation by completing the post-installation tasks See Oracle Real Application Clusters Postinstallation Procedures.
