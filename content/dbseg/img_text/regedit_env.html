Description of the illustration regedit_env.png

Image regedit_env.png shows the Edit Multi-String window in the Windows Registry Editor, with the following components, top to bottom, left to right:

The label Edit Multi-String at the top left, followed by the labels Value name, and Environment data

A field labeled Value data, with the following two lines, from top to bottom:

https_proxy=http://www-proxy-example.com:80/

http_proxy=http://www-proxy-example.com:80/

At the bottom right, from left to right, are the OK and Cancel buttons.
