Description for the illustration deployment_topology_datasovereignty_sharding

This illustration shows the components as an example for creating a sharded database on Oracle Cloud Infrastructure that spans three regions, Frankfurt (Region1 FRA), Amsterdam (Region 2 AMS), and London (Region 3 LON). Each region will host a shard director (Virtual Machine GSM) and one shard (System Database Shard 1, 2, and 3 respectively), and Region 1 (FRA) will host the shard catalog (System Database GSM Catalog Database).
