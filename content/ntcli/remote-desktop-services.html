Remote Desktop Services

Oracle supports installing, configuring, and running Oracle Database Client through Remote Desktop Services.

To install Oracle Database Client, Oracle recommends that you start all configuration tools from the Remote Desktop server console session of the server.

Platform-specific support information is as follows:

  • Windows client operating systems: The Remote Desktop is only available in Single User Mode.

  • Windows server operating systems: You can have multiple Remote Desktop sessions.
