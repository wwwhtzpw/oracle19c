94.2 Summary of DBMS_INMEMORY_ADVISE Subprograms

In Oracle Database 19c, DBMS_INMEMORY_ADVISE includes a single subprogram: IS_INMEMORY_ELIGIBLE.

Table 94-1 DBMS_INMEMORY_ADVISE Subprograms

Subprogram Description
IS_INMEMORY_ELIGIBLE Procedure Examines AWR snapshots to determine if a given workload will benefit or not benefit from the Database In-Memory feature.
